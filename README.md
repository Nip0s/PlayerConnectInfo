# PlayerConnectInfo

Плагин для CounterStrikeSharp (CS2), который выводит в чат сообщение о заходе и выходе игрока с сервера. Встроена защита от спама, чтобы при кратковременных реконнектах чат не засорялся.

- **Автор:** Nip0s
- **Версия:** 1.1.0

## Что делает

- При подключении игрока (после авторизации Steam) пишет в чат:
  `● <имя> подключился к серверу` (зелёный маркер).
- При отключении игрока пишет в чат:
  `● <имя> отключился от сервера` (красный маркер).
- **Anti-spam:** повторное сообщение для того же SteamID игнорируется, если с прошлого прошло менее 5 секунд.
- Боты и HLTV/GOTV прокси игнорируются.

## Требования

- CS2 dedicated server
- Metamod:Source
- CounterStrikeSharp

## Установка

1. Соберите плагин (`dotnet build -c Release`) или возьмите готовый `PlayerConnectInfo.dll`.
2. Скопируйте папку плагина в:
   ```
   game/csgo/addons/counterstrikesharp/plugins/PlayerConnectInfo/
   ```
3. Перезапустите сервер (или `css_plugins load PlayerConnectInfo`).

## Настройка

Отдельного конфига нет. Интервал anti-spam (`ANTI_SPAM_SECONDS`, по умолчанию 5 секунд) и тексты сообщений задаются в коде.

## Сборка

```bash
dotnet build -c Release
```
